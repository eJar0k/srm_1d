# Reference papers (not distributed)

The PDFs of the papers, reports and books this project cites are **not
tracked in git**; most are copyrighted. Keep your own copies in this folder:
`docs/references/*.pdf` is gitignored, and the code and probes look for them
here by these file names.

Full citations, DOIs and what each source is used for are in the documents
that cite them, for example:
- `docs/pyrogen_realism/PAYWALLED_REFERENCES.md`;
- `docs/pyrogen_realism/R9_SOURCES.md`;
- the design packages under `docs/v0_7_*` and `docs/erosive_model_registry/`.
