## 1. Step 1 -- mass-preserving rounding (memo 2.2)

* `build_snapped_geometry`: cumulative-position rounding (`pos_true` / `edge_cursor`); `GrainSegment.length_true`, `burn_scale = L_true / (n dx)` (exactly 1.0 when within 1e-12);
  `compile_geometry_arrays()['cell_burn_scale']`; `update_cell_geometry(..., cell_burn_scale=None)` multiplies `C_burn`; `total_propellant_volume` uses the true length
  (analytic / FMM) or the cell Riemann sum x `burn_scale` (tapered / OD). The plugin's per-grain mass and volume loading use the scale.
* The T10/QF1 regression fill debit must cancel the gas that fills the volume the cell's `A_port` opens, which grows with the UNscaled perimeter: `_goodman_ignition_sources_and_mass`
  divides `C_burn` by `cell_burn_scale` in `fill_vol` (found because `tests/test_energy_audit` closure degraded 1.0 -> 1.04 % without it, and restored with it).
* Gates:
  * `tests/test_g2_snap.py` (9 grids from 17 to 331 target cells): sum(C_burn) dx = pi D L_true to 1e-12; propellant volume = annulus x L_true to 1e-12; conical bore likewise;
    rounding error <= dx/2 on cumulative position (lumped and legacy builds); lengths that are whole cells keep scale 1.0 and identical geometry; end-face mass rate unchanged.
  * B0 at step 1 (vs G1): Hasegawa A **bit-identical** (rel 7e-16); Chunc peak 10.5104 -> 10.5078 MPa (-2.4e-4), t_peak 0.2591 -> 0.2689 s, plateau +9e-4, steps 543997 -> 543904
    (Chunc's grains are 15.6 / 84.4 cells -> scales 0.977 / 1.0045); BALLSstick (slow-ignition rows of G1) mid +0.2 %.
  * End-face conservation: unchanged (`test_endface_conservation` passes; plus `TestEndFaceAtWalls` and the 4-face test through the scale).

## 2. Step 2 -- inter-grain gap lumping (memo 2.1)

* `build_snapped_geometry(..., lump_gaps=True)` (default; `False` = legacy gap cells + `dx <= smallest gap` clamp, kept for A/B). `GrainSegment.gap_after`, `MotorGeometry.gaps_lumped`,
  `compile_geometry_arrays()['x_offset']`. An interface with a lumped gap is NOT auto-inhibited (bonded interfaces still are).
* Physical axis: `_run_time_loop` gets `x_offset`; `x_phys = x_centers + x_offset` feeds the Ma/Peretz x-from-head, HE1 jet (+ head gap), DeMar / radiation view factors, flame-front
  speed and pyrogen axial weights; `update_cell_geometry` keeps the contiguous cell axis. `result['x_offset']`, `AxialPayload.x_offset`, plugin payload `x_offset`; station positions are physical;
  the slice viewer's `x_cell` stays the contiguous cell axis (its cell rectangles of width dx tile it).
* Tests (`tests/test_g2_snap.py`, 27 in total): no gap cells and no clamp (N 100 vs 154); lumped volume conserved (and equal to the legacy gap cells' volume on a fine grid, 5e-3);
  the 50/50 split; x_offset; faces stay free; all four faces regressing through the lumps: end-face mass = 4 rho r A_face and gas volume gain = 4 A_annulus delta exactly (delta/dx = 0, 0.3, 1, 1.5, 3.7);
  fine-grid fill regression (example_bates at N = 250 and 400 survives the fill). Updated: `test_adapter` (2), `test_geometry` (2), `test_station_viz` (1).

`machbusterFAIL.ric` (a deliberately failing file that never ignites its grain) collapses in every configuration, before and after, as in G1.
The first G2 sweep (single-cell convergent lump) had one NEW collapse: `example_bates.ric` at N = 200 (step 2198, t = 1.30 ms, Mach 120).
Diagnosis (all on example_bates, 50 ms): collapses for N = 200 / 250 / 300 / 400 with lumped gaps; N = 150 and N = 100 run; with the legacy gap cells N = 250 / 300 run but **N = 400 collapses**
(so the weakness is G1's); `aft_end='none'` and `'cone'` run at N = 200 and 300; spreading the INTER-GRAIN lumps alone did not help; spreading the AFT lump (cap 1 at N = 200/300/400, cap 3 at N = 400) did.
Lump / host-cell volume ratios: head 4.5, interfaces 2.2, convergent 25 (N = 200) ... 50 (N = 400). Hence `lump_ratio_cap`. The cap is a stated stability assumption, not a fit: 1 = "storage at most doubles";
any value in 1 ... 3 was stable where tested, and the canonical motors move by 2e-4 (only Chunc's 4.9x convergent is spread). Per-motor rows: `G2_results/stab/`.
