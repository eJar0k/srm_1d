### Insertion point
Everything from "STEP 2: PRESSURE CORRECTION 1" through the energy update (STEP 3b, incl. the Mach limiter) is now the body
of `for it in range(K+1)`. The momentum predictor (`u_star`, from start-of-step state only) is outside the loop and is not redone.
Pass 0 is the original step (`T_comp = T`). Within a pass:
* `T_comp` (the T the compressibility is built from) replaces start-of-step `T` in exactly two places per corrector: the
  transient coefficient `a_t = A dx/(R T_comp dt)` and the intermediate density `rho_new_1 = P_after1/(R T_comp)` (which also feeds
  the face densities in corrector 2, the energy-equation mass fluxes and `new_mass`).
* Everything else keeps the start-of-step `T`: the nozzle boundary state, the explicit upwind enthalpy `Cp*T[i-1]`, `old_mass`
  `h_old`. (The explicit advection stays explicit; only compressibility is re-linearised.)
* After the energy update: `rel = max_i |T_new - T_comp|/T_comp`. If `it < K` and `rel < tol`: stop. If `it < K` and not
  converged: `T_comp <- T_new`, count one extra pass, repeat. At `it == K` stop regardless. Recorded per step: extra passes used
  (0..K) and `rel` of the last pass (for K=0 it is simply the step's own relative T change).
* `K = 0`: no extra branches execute (`it > 0` guard, `corr2_storage` False); B0 bit-identical (above).

### Algebra
Cell continuity (ledger form used by the energy equation), `rho* = rho(P,Tc)`:
`A dx (rho*_new - rho_n)/dt + (mdot_e - mdot_w) = S dx`, with `rho_n = P^n/(R T^n)` in a consistent state.
Corrector 1 linearises `rho*_new = (P^n+P')/(R Tc)`:
`a_t P' + div(d grad P') = S dx - flux(u*) - A dx (P^n/(R Tc) - P^n/(R T^n))/dt`.
The last term (thermal storage) is the only new term in pass k>0; it is 0 when `Tc = T^n` (so pass 0 is unchanged). It is
the physical coupling: heating at fixed P lowers rho, which must be offset by inflow (raising P).
Corrector 2 (original): `a_t P'2 + div(d grad P'2) = S dx - flux(u_new; rho_new_1)`. Note the right-hand side has NO storage term.
Since corrector 1 solved `a_t P'1 + [flux(u_new)-flux(u*)] = S dx - flux(u*)`, the corrector-2 right-hand side equals the
storage already taken, `A dx P'1/(R T dt)`, so P'2 re-applies it (see Finding below).
Optional ablation `corr2_storage=True` (S=1) adds `- A dx (P_after1/(R Tc) - P^n/(R T^n))/dt / ...` i.e.
`-(A dx/dt)(P_after1/(R Tc) - P^n/(R T^n))` to the corrector-2 residual (full continuity at the intermediate state; applies at
every pass incl. pass 0). Then at the fixed point `T_new = Tc`, `rho_new_1 = P_after1/(R T_new)` and `P'2 ~ 0`, so the carried
state `P_raw/(R T_new)` equals the ledger state: EOS jump -> 0.

### FINDING (outside the literal spec, found while checking whether the EOS jump can go to 0)
The EOS jump has two parts: (i) T-lag (`rho_new_1` built with `T_old` vs carried `T_new`) and (ii) the second pressure corrector
`P'2` applied AFTER `rho_new_1` is built (`eos_mass_jump_p2` = sum `(P_raw - P_after1)/(R T_new) A dx`). The literal iteration removes
only (i). Duct check (`P5_results/duct_closure_probe.py`, 20 cells, 3 source cells, no T change, dt 1e-6): ledger mass rate
0.26902 = expected 0.26906 kg/s, but **carried-state mass rate 0.53804** (2.0x); `eos/dt = p2/dt = 0.26902`. With S=1 carried =
0.26902. In the Chunc run (S=0, K=0, t<=50 ms, 106 cells) `eos_mass_jump_p2` signed is +1.62e-3 kg against EOS total +1.01e-3 kg
(T-lag part -0.6e-3 kg); with K>=1 the T-lag part is removed and the EOS mass jump equals the P'2 part (|EOS - P'2| shrinks ~1000x),
the EOS jump |J| barely changes (10428 -> 9460 J). S=1 is therefore an ablation of (ii), not of thread F; both are reported.

## Deviations / notes
* The spec's literal iteration cannot take the EOS jump to ~0 because of the P'2 component above; I added the `piso_corr2_storage`
  ablation (default off) so the T-lag and P'2 contributions can be separated. Literal-spec rows are the S=0 columns.
* Thermal-storage term added to corrector 1 for pass k>0 (spec says "rebuild the density/compressibility"; without the density-change
  term, changing `a_t` alone is not a consistent continuity equation). A first draft also added it to corrector 2; that double-counted
  the thermal rise (duct carried mass rate 1.74 vs 0.27 expected), so corrector 2 got the `corr2_storage` term instead.
* K=10 was run only for part A (K=3 had not converged the 1e-6 criterion on 4.6% of fill-window steps but state/outputs agree to 4-5 digits).
* Part B/C/D run at the spec grids (106/406/806) plus 1606; CFL 0.15 only in part B. Hasegawa A not run (not requested).
* The mixture-refresh / geometry-refresh jumps (5.9% of fill source energy at S=1) are untouched.
