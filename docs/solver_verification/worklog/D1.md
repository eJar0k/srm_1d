Reading:
* Every dead zone is gone (0 never lit on all three motors) and the Hasegawa A late peak moves to 0.95 of experiment.
* The charges shrink 21-36 % (the fallback stops at the first charge that lights the whole grain) and the ignition becomes progressive: Chunc first light 6.3 ms but t90 455 ms (the Chunc peak is now a late hump at 0.49 s rather than a startup spike); Hasegawa A t90 239 ms.

## Cost

* Fixed-charge Chunc 1 s (2.6226 g, cache-loaded, sequential, conduction): pre-D1 options 26.6k / 24.6k steps/s; D1 defaults 37.5k / 35.6k steps/s. The total-energy step itself costs about -15 % (EN1), but the
  conduction solid model is solved only for UNLIT cells, and with the jet no cell stays dark for the whole run, so the defaults run FASTER (+45 %) on Chunc.
* B0 wall time (fresh compile in both, 3 motors, auto-sized charges): before 98.5 + 83.8 + 168.6 = 351 s (Chunc 534k steps, BALLSstick 853k, Hasegawa A 2.35M); after 52.5 + 148.9 + 71.0 = 272 s (542k / 845k / 2.34M steps).
  BALLSstick is slower (3 sizing attempts at a slower per-step cost); Chunc and Hasegawa A faster (fewer attempts: Hasegawa A lights on the first attempt).
* B0 peak memory 2.5 GB.
