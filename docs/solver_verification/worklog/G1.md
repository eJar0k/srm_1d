## 0. Summary

1. **Lumped head volume was clean, so Option A was taken** (no fallback). The solver already separates the flow area from the storage area; one array
   `A_vol = A_port + vol_extra/dx` replaces `A_port` in ~25 storage sites in two files. `vol_extra = None`/zeros is bit-identical to before (tested).
2. **Head:** no head cells. A closure-to-grain gap exists only when the head face is uninhibited (default `max(3 mm, 5 % D)`), and is lumped in cell 0.
   A per-motor override exists (`run_from_ric(head_gap=)`, igniter block `head_gap_m`, plugin chamber field).
3. **Aft:** default `aft_end='lump'`: no aft cells; the volume of the nozzle convergent (cone from the case ID to the throat, half angle `convAngle`) is lumped into the
   last cell. `'cone'` (cone cells, cut by the nozzle BC's own reservoir assumption) is opt-in; with the real `convAngle`s and dx of the canonical motors it adds 0-3 cells.
4. **The startup is now grid independent** (Chunc, forward plenum, 2.62 g, defaults): peak 16.36 / 16.43 / 16.37 MPa and first light 1.10 / 0.82 / 0.84 ms at N = 50 / 100 / 200.
5. **Removing the pocket alone does NOT remove the dead zones** (HE1 off): Chunc 9 -> 3 cells, BALLSstick 8 -> 3 cells, Hasegawa A 8 -> 10 cells. The dark block is now at the closure (cells 0-2 /
   0-9) instead of behind the pocket (cells 3-11); it is ~30 mm long for Chunc at every N (so a physical zone, not a grid artifact). With HE1 (the D1 default) they light.
6. **The physical (zero) head gap makes the startup much more violent** (MU1 predicted it): Chunc at 2.62 g 11.7 -> 16.4 MPa (ratio vs the plateau 1.44 -> 2.00; exp 1.027), BALLSstick pk/tr 2.4 -> 3.8
   (exp ~1.5), Hasegawa A gets an early spike (6.75 MPa) on top of the unchanged late peak (6.11 MPa = 0.95x exp).
7. **Auto charges fall ~25-60 %** (the free volume used by the DeMar sizing no longer contains the fictitious buffer volume; and the self-sustaining fallback then stops earlier). BALLSstick's auto charge
   (1.27 g) lights the grain over ~1 s: see section 6 (needs a user decision; B0's BALLS row is therefore not a startup spike/trough gate any more).
8. **Stability:** 21 committed motors x {old ends, new default ends, cone variant, N = 200}: no new collapse; one old-ends collapse (L1843) is gone; `machbusterFAIL.ric` collapses before and after (section 5).
9. Gates: B0 re-recorded and PASS (warm); full suite and the end-face conservation tests: section 8.

## 1. Part 1 -- head end: the path, and the map of the storage terms

Path: **lumped (Option A)**. Why: every gas volume in the code is written `A_port[i] * dx`, while the flow areas are built separately (`A_face`, the centre mass flux); so storage and flow can be separated by passing one extra
array, with no change to any equation's structure. Map (all `A_port[i]*dx` volumes -> `A_vol[i]*dx`; flow areas untouched):

| file | site | role |
|---|---|---|
| `solver.py` `_piso_step_with_energy_diagnostics` | `a_t` of pressure correction 1 and 2; P5 re-compressibility term; correction-2 storage term | pressure matrix storage |
| same | `rho_pred` (conservative momentum) `mass_source/A`, flux-divergence `/(A dx)` | predicted density |
| same | sensible-energy `old_mass`/`new_mass`; floor mass; EOS/mass-jump accounting (`old_mass_acct`, `new_mass_acct`, `m_eos_acct`, P2 jump); `m_floor_i`; limit-tally mass | energy + ledgers |
| `solver.py` `_total_energy_update` | `old_mass`, `new_mass` (called with `A_vol`) | total energy |
| `solver.py` `compute_dt_source_cap` | thermal capacity `rho A Cp` (called with `A_vol`) | source-CFL |
| `simulation.py` `_advect_species` | `V_i` (new arg `A_vol`; face area stays `A_port`) | species |
| `simulation.py` `_gas_*`/`_ledger_mass_energy` | called with `A_vol` (energy-audit ledgers, geometry-refresh jump) | ledgers |
| `simulation.py` `_run_time_loop` | head-basket `P_ig` volume average; `A_vol` refreshed after every `update_cell_geometry` | misc |

Unchanged on purpose: `A_face`, `mdot_jm1/mdot_j` (momentum convection), face areas in the species/energy fluxes, friction and `D_hyd`, `mass_source * dx` (kg/s per length, independent of volume).
The momentum control volume is not given the lump (its mass is taken from the face density; the gap volume is dead volume for the gas inertia). Tests: `tests/test_g1_ends.py::TestLumpedStorage`
(bitwise default, the ledger counts the lumped volume, the pressure rise of the same injected mass falls as 1/V).

Geometry: `build_snapped_geometry` no longer adds `MIN_BUFFER_CELLS` cells (cell 0 is the first grain cell). `MotorGeometry.head_gap/aft_end/n_cone_cells/cone_D_start/cone_half_angle/aft_lump_volume`;
`compile_geometry_arrays()['vol_extra']`; `MotorGeometry.initial_gas_volume()` (used for the DeMar auto charge instead of `case cylinder - propellant`).

Re-checked head-end paths with cell 0 a grain cell:
* forward-plenum injection: mass/enthalpy/momentum into cell 0 / face 1 and the `L_jet` weights: the weights use `x + head_gap` (distance from the closure); unchanged at gap 0.
* `head_grain_cell` (first grain cell with burning surface): now cell 0; the DeMar/radiation paths are opt-in and index by cell, unchanged. `tests/test_ignition_diagnostics` updated (cell 0 heated, then the next unlit head cell).
* HE1 jet h: `x_from_head = x_centers + head_gap` (new `head_gap` arg of `_goodman_ignition_sources_and_mass`). At the closure itself (cell 0, x = dx/2) the Peretz III-29 multiplier is `0.022 + 0.066 x/x_im`,
  its smallest value, so cell 0 is the hardest cell to light even with the jet (section 6).
* head/aft basket ranges: `resolve_injection_cells(..., head_gap=)` subtracts the gap from the cartridge length for the head basket; the aft basket is unchanged.
* end-face hat function at the walls: the existing `i == 0 and x_fwd < x` / `i == N-1 and x_aft > x` clauses already give the whole face mass to the wall cell (partition of unity);
  `tests/test_g1_ends.py::TestEndFaceAtWalls` checks it for regressed faces and `test_endface_conservation.py` passes unchanged.
* history/snapshot indexing and the GUI payload: data-driven (`is_grain`, `cell_segment_id`); `station_viz.cell_categories` only emits Head if cells precede the first grain, so Head disappears and cone cells (if any) are "Aft".
  The OD-taper "pin" of buffer cells in `compile_geometry_arrays` was removed (nothing left to pin); `test_taper` updated.

## 2. Part 2 -- aft end: candidates and evidence

Convergent geometry: cone from `D_start` (casing ID at the grain aft end) to `D_throat`, half angle `convAngle` (as openMotor's nozzle preview), `L = (D_start - D_t)/(2 tan a)`, volume = frustum.
Canonical motors (N = 100): Chunc cone 18.2 mm (dx 8.1 mm), 16.1 cm^3 = 7 % of the gas volume; BALLSstick cone 9.1 cm^3; Hasegawa A 35.7 cm^3. With the committed angles (40 / 75 / 60 deg) the cone is shorter than 1-2 cells.

Candidates (Chunc forward plenum 2.62 g, jet max, **pre-D1 sensible form**, `results aft/`; peak [MPa], plateau [MPa], first light [ms]):

| aft mode | N = 50 | N = 100 | N = 200 | N = 400 |
|---|---|---|---|---|
| `none` (last grain cell at the BC, convergent volume dropped) | 16.35 / 8.23 / 1.10 | 16.41 / 8.24 / 0.84 | 16.35 / 8.25 / 0.86 | - |
| **`lump`** (convergent volume in the last cell) | - | 16.30 / 8.24 / 0.84 | 16.24 / 8.25 / 0.86 | 16.24 / 8.25 / 0.84 |
| `cone` v1: cells down to the grain's initial aft port area (rejected) | 15.85 / 8.29 / 1.10 | 15.58 / 8.27 / 0.84 | 15.83 / **8.71** / 0.86 | - |
| `cone_nolump` (N = 100) | | 15.59 / 8.27 / 0.84 | | |
| `cone` v2: cut by the BC reservoir error (1 % in P0) + rest lumped | 16.24 / 8.23 / 1.10 | 15.76 / 8.26 / 0.84 | 15.54 / 8.23 / 0.86 | 15.56 / 8.24 / 0.84 |

BALLSstick (cone length < dx so cone == lump) and Hasegawa A: `lump` vs `none` differ by 0.2 % (BALLS peak 16.577 vs 16.606 MPa; Hasegawa A early 6.677 vs 6.682, late 6.115 vs 6.115).
The aft treatment moves the results by ~1 % (as MU1 found); the lumped volume is a 0.4 % effect on the peak.

Failed candidate and why: **cone v1** (cells wherever the cone area >= the grain's initial aft port area). The nozzle BC (`_nozzle_boundary_flow`) takes the last cell's static T and P as stagnation. A cone cell has a FIXED area while the grain
port opens up, so its Mach (A/A_t = 2.2 -> M ~ 0.28 at N = 200) keeps biasing the inferred P0 (P0/P - 1 ~ gamma M^2 / 2 ~ 5 %) for the whole burn: the plateau rose 5 % at N = 200 and drifted with resolution. The justification "no worse than the grain exit at t = 0" was
true at t = 0 only. **cone v2** therefore keeps cone cells only where the BC error stays below `p0_tol` = 1 % in P0 (area ratio 4.64 for gamma 1.2, `bc_reservoir_area_ratio`, a STATED model assumption; 0.5 % -> 6.52, 2 % -> 3.32), and lumps the rest.
It is plateau-neutral (8.23-8.26) but its startup peak wanders +-2 % with N (cells appear and disappear), so it is not the default.

Chosen default: **`lump`**. No free parameter (a function of throat, case ID and `convAngle` only), the most grid independent (peak 16.30 / 16.24 / 16.24 at N = 100 / 200 / 400), no BC bias, stable.
The cone-cell variant stays available (`aft_end='cone'`) for a future BC that uses the local Mach.

Finding for the user (not changed): the BC's reservoir assumption already carries an error at the grain exit: Chunc `A_port,aft/A_t = 1.8` at t = 0 (M ~ 0.35, P0 under-stated ~7 %), falling as the port opens (BALLSstick 1.86, Hasegawa A 1.38).
A BC that uses the cell velocity to form the stagnation state would remove it; it would shift every plateau, so it is a calibration decision, not part of G1.

## 6. Findings for the user

1. **Dead zones (HE1 off):** removing the pocket alone does not remove them. Chunc 9 (cells 3-11) -> 3 (0-2); BALLSstick 8 (3-10) -> 3 (0-2); Hasegawa A 8 (3-10) -> 10 (0-9, 168 mm). The block moved to the closure, i.e. the old pocket was
   hiding the head-most cells from the low-h region rather than causing it. With HE1 on (default) the fixed-charge rows have 0 dark cells.
2. **With HE1 on, cell 0 can stay dark at the reduced auto charges** (Chunc 0.81 g, BALLS 1.27 g, Hasegawa A 7.86 g: cell 0 only, never lit): Peretz III-29's multiplier is smallest at x -> 0 (the closure).
3. **BALLSstick's auto charge is now too small for a prompt start.** The DeMar charge on the physical free volume (1.27 g, accepted on the first attempt by the IG4 criterion "grain out-produces the igniter"), but the grain then lights over 971 ms (t90) and P stays below 0.3 MPa for the first ~0.3 s.
   B0's BALLS row (largest P in the first 0.3 s, trough, mid) is therefore a slow-ignition measurement now (peak 0.295, trough 0.076, mid 6.70 MPa); its recorded values are G1's, flagged in the comment. Options for the user: tighten the auto-size success test (e.g. require the lit fraction by a time), or size on the pre-G1 volume. I did not change it.
4. **The startup over-prediction grows** once the physical zero head gap is used (Chunc ratio at fixed 2.62 g 1.44 -> 2.00 with the jet; at the auto charge 1.23 -> 1.31; exp 1.027). This is what MU1 predicted (peak 23.6 MPa at a 24 mm gap vs 33 MPa at 3 mm for 10 g). It is not a G1 defect;
   it removes a fictitious damping volume and exposes the ignition-spike problem again at its physical head gap. The head gap is now a physical input (`head_gap_m`).
5. Hasegawa A late peak is robust: 6.103 -> 6.111 MPa (fixed charge), 6.109 -> 6.017 (auto; the charge is smaller).
