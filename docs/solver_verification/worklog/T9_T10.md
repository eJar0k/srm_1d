# T10 -- subtract the gas that fills newly opened port volume

## Change
`srm_1d/simulation.py::_goodman_ignition_sources_and_mass`: after the per-cell
source assembly (and AFTER `mass_sum += mass_source[i]`, so `mass_sum` /
`total_mass_produced` stay GROSS generation), for each cell
`fill_vol = r_total*C_burn [if burning] + endface_msource/rho_p` (same effective
rate x area as the sources; `f_active` already inside `C_burn`; end face = both the
sidewall-like and end-face open new volume). Then `mass_source -= rho_g*fill_vol`,
`thermal_source -= rho_g*Cp_mix*T*fill_vol`, `mass_source_by_species[:,k] -=
rho_g*Y_k*fill_vol` (local mixture; start-of-step `rho`, `Cp_mix_arr`, `T`, `Y_species`
-- passed as two new trailing args `rho_gas`, `Cp_mix_gas`). Two new return values
(`fill_debit_massflow` kg/s, `fill_debit_power` W) -> new history arrays and result
keys `regression_fill_debit_massflow/_power`; `source_ledger_mismatch_W` now includes
`- fill_debit_power`. Momentum left UNCHANGED (not measured by T6). Other files:
`tools/ignition_diagnostics.py` (two new keys in the timeseries key lists),
`tests/test_simulation_phase3.py` (2 direct kernel calls pass the 2 new args),
`tests/test_energy_audit.py` (+2 tests: debit cancels geometry jump within 1%; source
ledger closes), `DEVNOTES.md` (log entry + Calibration State note),

`worklog/T10_scripts/measure.py` (driver).

**The cancellation is NOT to round-off** (spec expectation): it is 1e-5 relative on
Chunc and 1.6e-3 on BALLSstick. Cumulative check over the run (BALLS): rel difference
4.7e-4 @ 0.085 s, 1.4e-3 @ 0.45 s, 4.3e-4 @ 1.46 s, 3.6e-4 @ 1.78 s, 1.6e-3 @ 2.0 s
(burnout decile); Chunc: -4e-5 ... -8e-6, i.e. it never exceeds 0.2%. Plausible causes
(NOT separately isolated): debit uses start-of-step rho whereas the geometry jump
uses rho at the refresh; end-face hat-kernel weights vs the grain_frac overlap
blend; the forced-burnout clamp in `advance_bore_regression`; taper (BALLS) geometry.
Per-category net remaining jump after T10 (geometry - debit) is <= 87 J / 1.4e-5 kg,
vs 40-54 kJ / 6-9 g before.

`mass_balance_error` got LARGER, by design: it is |gross produced - nozzle| / theoretical,
i.e. the stored bore-gas inventory. Before, the +6.4 g geometry artifact (always
positive) partially cancelled the inventory. Check (Chunc, t=1.0): produced - nozzle =
7.35 g vs snapshot-integrated stored gas (end - start) 7.74 g (approximate: circular
D_port, snapshot ~0.1 ms before end) -- consistent.
